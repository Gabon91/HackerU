# Gabi Levi - Personal Portfolio Website

A personal portfolio website showcasing my background, skills, and interactive web projects.  
Built with **HTML5**, **CSS3**, and **JavaScript** — no frameworks or external libraries.

## 🌐 Overview

This is a fully responsive, RTL (Right-to-Left) Hebrew website serving as a personal portfolio and project showcase for Gabi Levi — a Full Stack Developer and M.Sc. Computer Science graduate.

### Main Sections
- **About** — Personal background, education, and skills
- **Projects** — Six interactive web projects (see below)
- **Contact** — Gmail, LinkedIn, WhatsApp, phone, and location info

---

## 🚀 How to Run

1. Clone or download this repository.
2. Open `Gabi_Levi_Website/index.html` in any modern web browser.
3. No server, build tools, or installations required — everything runs client-side.

> **Tip:** You can also use a local server (e.g., VS Code Live Server extension) for the best experience.

## 🎮 Projects

### 1. Tic Tac Toe (`p1_TicTacToe`)
Classic two-player X & O game with custom image buttons, score tracking, and a restart feature.

### 2. To-Do List (`p2_TODO_List`)
Task management app with add, edit, delete, and mark-as-complete functionality. Supports exporting and importing task lists as JSON files, plus a clear-all button.

### 3. Interactive Calendar (`p3_Calendar`)
Full-featured calendar with day/week/month views, event creation via click-to-add popups, event deletion, and JSON import/export for saving personal events.

### 4. Sudoku (`p4_SuDoKu`)
Randomly generated Sudoku puzzles built in pure JavaScript. Features include cell highlighting, number pad input, error detection, timer, and win detection.

### 5. MineSweeper (`p5_MineSweeper`)
Classic Minesweeper with a 9×9 grid, 10 mines, right-click flagging, first-click safety, flood-fill reveal, smiley game-state indicator, and timer.

### 6. Tetris (`p6_Tetris`)
Classic Tetris built with HTML5 Canvas. Features all 7 tetrominoes, scoring with level progression, increasing speed, timer, and hard-drop support.
