# Gabi Levi – Portfolio Website

A personal portfolio website built by **Gabi Levi** as a course assignment for the **HackerU Academy** fullstack developer program.

## About

Gabi is a software developer with a Master's degree in Computer Science and 14 years of experience developing advanced technological systems in the IDF. This site showcases his background, skills, and mini-projects built during the course.

## Project Structure

```
Gabi_Website/
├── index.html            # Main landing page (bio, skills, contact)
├── projects.html         # Project gallery with 6 clickable cards
├── style/
│   └── styles.css        # Global stylesheet
├── xo_game.js            # Tic-Tac-Toe game (work in progress)
├── country_project.js    # Fetches country data from REST Countries API
├── todolist.js           # To-do list app (work in progress)
└── foo.md                # This file
```

## Tech Stack

- **HTML5** – Semantic markup with RTL (right-to-left) Hebrew layout
- **CSS3** – Dark theme (`#1e1e2f`), responsive grid, hover animations
- **JavaScript (ES6+)** – DOM manipulation, `async/await`, Fetch API

## Features

- **Responsive design** – Adapts to mobile (1 column), tablet (2 columns), and desktop (3 columns)
- **Project gallery** – Grid of cards with hover effects linking to individual projects
- **Country explorer** – Fetches and displays country names, capitals, currencies, and flags from the REST Countries API
- **Tic-Tac-Toe game** – Interactive cell-click handling (in progress)

## Getting Started

1. Clone the repository.
2. Open `index.html` in a browser to view the main page.
3. Navigate to `projects.html` to browse the project gallery.
